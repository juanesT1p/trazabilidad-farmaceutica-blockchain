# Decisión: qué va en cadena y fuera de cadena

Las firmas ML-DSA y el JSON completo quedan fuera de cadena porque una firma ML-DSA-65 mide 3309 bytes en la ejecución local. En cadena solo se fijan hashes, custodio y reglas de autorización. La base de datos conserva firma, evento, transacción y bloque para reconstrucción y auditoría académica.
